# Beaconfield International Academy 🎓

A modern, responsive, and high-performance school website built with vanilla HTML5, CSS3, and modern JavaScript (ES6+).

![Beaconfield Academy](assets/images/hero.webp)

## 🌟 Key Features

- **Accredited Global Curriculum Showcase**: Detailed overviews and interactive curriculum modals for Early Childhood, Cambridge Primary, Middle School MYP, and Upper School / IB Diploma.
- **Interactive Tuition & Aid Estimator**: Real-time calculator calculating annual investment based on grade level, residential status (day/boarding), transit, dining, and scholarship grants.
- **Campus Facilities Showcase**: High-resolution gallery featuring the 65-acre campus quad, modern STEM & robotics laboratories, sunlit media center/library, and Olympic athletics stadium.
- **Interactive Modals**:
  - 📝 **Admissions Application Modal (2026-2027)** with real-time feedback.
  - 🏫 **Campus Tour Booking System** with date & time slot selection.
  - 🔐 **Student & Parent Portal Login Modal**.
  - 📚 **Curriculum Detail Popups** with specific division insights.
- **Events & Community Calendar**: Up-to-date events schedule with one-click interactive RSVP notifications.
- **Dark & Light Mode**: Built-in sleek dark mode toggle with persistent `localStorage` preference.
- **Optimized for Web Performance**:
  - Next-gen WebP images with progressive JPEG fallbacks.
  - Over 80% reduction in image weight for blazing-fast page loads.
  - Semantic HTML5 with accessibility tags and mobile-first responsive design.

## 🚀 Quick Start / Local Development

No build step or external dependencies required! Simply open `index.html` in your browser, or start a lightweight local server:

### Using Python:
```bash
python -m http.server 3000
```
Then visit [http://localhost:3000](http://localhost:3000).

### Using Node.js:
```bash
npx serve .
```
